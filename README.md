# My Web Development Learning Journey

## About This Project

This repository documents my journey as I learn **Web Development** as a Bachelor of Science in Information Technology (BSIT) student.

When I started learning web development, I was mainly interested in understanding how websites are created. As I continued learning, I began to understand that web development is not only about creating pages that look good, but also about understanding how different technologies work together to create useful and interactive applications.

## What I Have Learned

Through my web development studies and practice, I have learned the basics of:

* **HTML** — how to structure web pages using elements such as headings, paragraphs, links, images, forms, and other content.
* **CSS** — how to style web pages, control layouts, work with colors, spacing, fonts, and make pages more attractive.
* **JavaScript** — how to add logic and interaction to websites and make pages respond to users.
* **Git and GitHub** — how to create repositories, track my work using commits, organize projects, and keep a record of my development progress.
* **Project organization** — how to organize files and folders so that a project is easier to understand and maintain.
* **Problem solving** — how to break a problem into smaller parts and use programming concepts to find solutions.

## How Web Development Has Helped Me

Learning web development has helped me become more confident in technology and programming.

It has helped me understand what happens behind the websites and applications that I use every day. Instead of only being a user of technology, I am beginning to understand how I can become someone who **creates technology**.

It has also improved my problem-solving skills. When something does not work in my code, I have learned to look at the problem, understand what went wrong, and try different solutions.

Most importantly, web development has shown me that I can turn my ideas into real projects.
